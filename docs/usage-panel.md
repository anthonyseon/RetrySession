# 사용량 패널 — 그 숫자는 어디서 왔나

> 화면 맨 위의 접이식 `사용량` 패널 하나를 설명한다. 나머지 화면은 [`../Manual.md`](../Manual.md).
>
> 🔴 요지 한 줄: **창 사용률(%)은 Claude 계정의 공식 값이고, 토큰은 우리가 센 값이다.**
> 둘은 단위가 달라서 **나누지 않는다.** 섞으면 어느 것이 실측이고 어느 것이 추정인지 사라진다.

## 네 묶음, 네 출처

| 묶음 | 출처 | 성질 |
|---|---|---|
| **창 사용률** `Session (5hr)` · `Weekly (7 day)` | Claude 계정 (`GET /api/oauth/usage`) | **공식 값.** 대화 안 `/usage` 화면과 같은 숫자 · 초기화 시각 포함 |
| **Claude 가 말하는 사용량** | `claude -p /usage` | **근사값.** 최근 24시간·7일의 요청·세션 수와 성질(긴 컨텍스트·장시간·병렬) |
| **사용량 제한** | 트랜스크립트의 `quotaLimits` | **관측한 시점**의 기록. 지금 상태가 아닐 수 있다 |
| **우리 실측** | 트랜스크립트 집계 | 오늘/누적 토큰·정가 환산·모델별. 이 기계의 로컬 세션만 본다 |

펼칠 때 한 번 읽고, 그 뒤로는 `갱신` 을 누를 때만 다시 읽는다 — `/usage` 호출이 몇 초 걸려
폴링에 넣지 않았다(토큰은 쓰지 않는다). 숫자를 못 뽑으면 **원문**을 그대로 남긴다.

## 공식 사용률을 어디서 받나 (실측 2026-09-29)

대화 안에서 `/usage` 를 치면 나오는 막대는 **CLI 로는 받을 수 없다.** 세 곳을 확인했다:

| 찾아본 곳 | 사용률(%)이 있나 |
|---|---|
| `claude -p /usage --output-format json` | **없다** — 「무엇이 한도를 먹었나」 본문만 온다 |
| 트랜스크립트의 `quotaLimits` | **없다** — `status`·`resets_at`·`rateLimitType`·`overageStatus` 뿐 |
| `claude auth status --json` | **없다** — 계정·요금제 종류까지 |

그래서 **대화 화면이 쓰는 그 자리**에서 직접 받는다(`src/lib/oauth-usage.mjs`):

```text
GET https://api.anthropic.com/api/oauth/usage
Authorization: Bearer <VS Code 에 로그인된 계정 토큰>
→ five_hour.utilization · seven_day.utilization · 각 resets_at · limits[].severity
```

실측으로 이 값이 사용자가 `/usage` 에서 본 숫자와 그대로 일치했다(`Session 9% · Weekly 40%`).

### 토큰 취급 — 네 가지 규칙

1. **API 키를 만들지 않는다.** `~/.claude/.credentials.json` 의 로그인 토큰을 쓴다(CLAUDE.md §6).
2. **보내는 곳은 `api.anthropic.com` 하나뿐**이다. URL 에 넣지 않고 헤더로만 간다.
3. **어디에도 남기지 않는다** — 응답 객체·오류 문구·로그·`state/` 전부. 시험이 그것을 센다.
4. **갱신하지 않는다.** 만료됐으면 「Claude Code 를 한 번 열면 갱신됩니다」라고 말하고 멈춘다.

### 문서에 없는 자리다 — 그래서 깨지면 깨졌다고 말한다

이 응답 서식이 바뀌면 숫자는 사라진다. 그때 화면은 **빈칸이 아니라 이유**를 보여준다:
`받지 못함` + 무엇이 실패했는지(파일 없음 · 만료 · 401 · 서식 변경 · 그물 끊김).
🔴 **실측 토큰으로 그 칸을 메우지 않는다** — 메우면 그게 다시 추정이고, 사람은 그 숫자를 믿는다.

> 지난 결함(2026-09-29): 한동안 우리는 «실측 ÷ 제한 사건에서 배운 기준선» 으로 퍼센트를
> 추정했다. 사용자가 `/usage` 에서 본 값은 `Session 7% · Weekly 40%` 였는데 화면은 **100%** 를
> 보여줬다. 한도의 단위도, 창이 언제 시작하는지도 우리가 모르므로 추정으로는 맞출 수 없었다.
> 그 기계(기준선 학습·자기 교정 · `state/limits.json`)는 걷어냈다.

## 우리 실측 토큰은 왜 남겨 두나

공식 퍼센트는 «얼마나 남았나» 를 말해주지만 **무엇이 그것을 먹었나** 는 말해주지 않는다.
모델별 몫·오늘 지출·세션별 비용은 우리 집계만 안다. 그래서 같은 줄에 **참고**로 붙인다.

- 창은 **굴러가는 창**이다(지금부터 거꾸로 5시간·7일). 공식 창은 초기화 시각이 정해져 있어
  경계가 다르다 — 그래서 두 숫자를 나누면 안 된다.
- 통은 한 시간 단위이고 31일치를 들고 있다(`src/lib/hours.mjs`). 경계는 **넓게 잡는 쪽**으로
  기운다 — 적게 보이게 기울면 「여유 있다」는 거짓이 된다.
- 이 기계의 로컬 세션만 본다. 다른 기기·claude.ai 사용은 안 보인다.

계약은 `test/oauth-usage.test.mjs`(13개) · `test/limit-window.test.mjs`(12개) ·
`test/usage-panel.test.mjs`(17개) 가 못박는다.
